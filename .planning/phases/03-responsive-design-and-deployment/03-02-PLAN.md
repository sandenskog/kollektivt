<task type="auto">
  <name>Task 1: Create Docker and nginx configuration files</name>
  <files>Dockerfile, docker-compose.yml, nginx.conf, .dockerignore</files>
  <action>
    1. Create `Dockerfile` (multi-stage build):
       ```dockerfile
       FROM node:22-alpine AS build
       WORKDIR /app
       COPY package.json package-lock.json ./
       RUN npm ci
       COPY . .
       RUN npm run build

       FROM nginx:alpine
       COPY --from=build /app/dist /usr/share/nginx/html
       COPY nginx.conf /etc/nginx/conf.d/default.conf
       EXPOSE 80
       ```

    2. Create `nginx.conf`:
       ```nginx
       server {
           listen 80;
           server_name localhost;
           root /usr/share/nginx/html;
           index index.html;

           location / {
               try_files $uri $uri/ /index.html;
           }

           location /assets/ {
               expires 1y;
               add_header Cache-Control "public, immutable";
           }
       }
       ```

    3. Create `docker-compose.yml`:
       ```yaml
       version: "3"
       services:
         kollektivt:
           build: .
           ports:
             - "3300:80"
           restart: unless-stopped
       ```

    4. Create `.dockerignore`:
       ```
       node_modules
       dist
       .git
       .planning
       **/@eaDir
       *.md
       ```

    5. Verify Docker build locally:
       ```bash
       docker build -t kollektivt .
       ```
       If Docker is not available locally, verify with `npm run build` that the build step succeeds.
  </action>

    2. Build and start Docker container on NAS:


    5. Create reverse proxy rule for kollektivt.sandenskog.se:
       SSH into NAS and run a Python script to add entry to `/usr/syno/etc/www/ReverseProxy.json`:
       - backend: localhost:3300, protocol: 0 (http)
       - frontend: kollektivt.sandenskog.se:443, protocol: 1 (https)
       - Regenerate nginx: `synow3tool --gen-all && synow3tool --nginx=reload`


    7. Link certificate to reverse proxy rule:
       - Update `/usr/syno/etc/certificate/_archive/INFO` to map the reverse proxy service to the new cert ID
       - Copy cert files to `/usr/syno/etc/certificate/ReverseProxy/<rule-uuid>/`
       - Reload: `synow3tool --gen-all && synow3tool --nginx=reload`

    8. Test final URL:
       ```bash
       curl -s -o /dev/null -w "%{http_code}" https://kollektivt.sandenskog.se
       ```
       Expected: 200
